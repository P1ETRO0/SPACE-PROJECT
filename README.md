# Space Project

## Descrição
O Space Project é um projeto web que explora o tema do espaço, apresentando informações sobre tripulação, destinos e tecnologias relacionadas ao universo espacial. Ele utiliza HTML, CSS e JavaScript para criar uma experiência interativa e visualmente atraente.

## Estrutura do Projeto
A estrutura do projeto é organizada da seguinte forma:

```
space-project/
├── crew.html
├── crew.js
├── data.json
├── destination.html
├── index.html
├── nav.js
├── script.js
├── style.css
├── tech.html
├── tech.js
└── assets/
    ├── crew/
    ├── destination/
    ├── home/
    ├── shared/
    └── technology/
```

### Principais Arquivos
- **index.html**: Página inicial do projeto.
- **crew.html**: Página dedicada à tripulação.
- **destination.html**: Página com informações sobre destinos espaciais.
- **tech.html**: Página sobre tecnologias espaciais.
- **style.css**: Arquivo de estilos para o projeto.
- **script.js**: Script principal para funcionalidades gerais.
- **nav.js**: Script para navegação entre páginas.
- **data.json**: Contém dados estruturados usados no projeto.

### Diretório `assets`
- **crew/**: Imagens relacionadas à tripulação.
- **destination/**: Imagens dos destinos espaciais.
- **home/**: Recursos visuais da página inicial.
- **shared/**: Recursos compartilhados entre páginas.
- **technology/**: Imagens e recursos relacionados às tecnologias.

## Como Executar
1. Clone este repositório para sua máquina local:
   ```bash
   git clone <URL_DO_REPOSITORIO>
   ```
2. Navegue até o diretório do projeto:
   ```bash
   cd space-project
   ```
3. Abra o arquivo `index.html` em seu navegador preferido.
